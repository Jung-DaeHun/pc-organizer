내 컴퓨터의 파일·폴더·설치된 앱 현황을 한 화면에서 보고, 정리할 거리를 찾아주는 Windows 데스크톱 앱입니다. 첫 공개 버전입니다.

## 무엇을 하나

- **드라이브 용량** — 로컬 드라이브별 사용량과 여유 공간
- **감시 폴더** — 다운로드·바탕화면 등 등록한 폴더의 파일 수·용량·종류별 구성
- **정리 기회** — 중복 후보, 임시파일·휴지통, 대용량, 오래된 파일
- **정리 계획** — 감시 폴더 바로 아래의 파일·폴더를 칸반 보드에서 폴더별로 나누고, **실행**하면 그대로 옮깁니다. 실행 기록이 남아 **실행취소**로 되돌릴 수 있습니다
- **중복 후보 정리** — 크기와 앞부분이 같은 파일 그룹에서 남길 하나를 고르면 나머지를 **윈도우 휴지통**으로 보냅니다
- **설치된 앱** — 설치 프로그램 목록과 용량을 검색·정렬로 훑어보고 윈도우 설정(앱 > 설치된 앱)으로 넘어갑니다. 제거는 거기서 직접 합니다
- **설정** — 테마(어둡게·밝게), 확장자 분류 규칙, 대용량·오래된 파일의 판정 기준

## 영구 삭제는 없습니다

이 앱이 사용자 파일에 하는 일은 **옮기기**와 **휴지통으로 보내기** 둘뿐입니다. 파일을 영구 삭제하는 코드는 어디에도 없습니다.

- 옮긴 것은 실행취소로 원래 자리에 돌아갑니다. 이름을 바꾸지 않고, 덮어쓰지 않고, 다른 드라이브로 복사하지 않습니다. 옮기기 전 점검에서 하나라도 걸리면 아무것도 옮기지 않습니다.
- 휴지통으로 보내는 건 중복 후보뿐이고, 보내기 전에 그룹의 파일 전체를 다시 비교합니다. 드라이브의 휴지통 최대 크기보다 큰 파일이나 '휴지통을 쓰지 않음' 드라이브처럼 윈도우가 휴지통을 거치지 않고 지워 버리는 경우는 보내지 않습니다. 되돌리기는 윈도우 휴지통에서 복원합니다.
- OneDrive 온라인 전용 파일의 내용은 읽지 않습니다(읽으면 자동 다운로드가 시작됩니다). 심볼릭 링크·정션은 따라가지 않습니다.

## AI 추천은 선택 사항입니다

Anthropic API 키를 넣으면 파일 **이름·종류·크기·수정일만** 보내 의미로 묶은 폴더를 제안받습니다. 키가 없어도 나머지 기능은 전부 됩니다.

- 보내기 전에 무엇을 보내는지 먼저 보여주고 확인을 받습니다. 파일 내용·전체 경로·사용자 이름은 보내지 않습니다.
- AI는 이동·분류만 제안합니다. 삭제는 제안할 수 없습니다.
- 키는 Windows DPAPI로 암호화해 저장되고 화면으로 다시 돌아오지 않습니다.
- 네트워크로 나가는 경로는 이것 하나뿐입니다. 자동 업데이트·사용 통계 전송은 없습니다.

## 설치

`pc-organizer-setup-0.1.0.exe`를 내려받아 실행합니다. Windows 10/11 64비트.

- 관리자 권한 없이 현재 사용자 폴더(`%LOCALAPPDATA%\Programs\pc-organizer`)에 설치되고, 시작 메뉴·바탕화면 바로가기를 만듭니다.
- 설정·API 키·실행 기록은 `%APPDATA%\pc-organizer`에 저장됩니다.
- 제거는 윈도우 설정 > 앱 > 설치된 앱에서 "PC 정리 도구"를 고릅니다.

### 실행할 때 뜨는 경고

설치 파일에 **코드 서명이 없습니다.** 그래서:

- **SmartScreen** — "Windows의 PC 보호" 창이 뜹니다. **추가 정보 → 실행**으로 넘어갑니다.
- **스마트 앱 컨트롤이 켜진 PC**(Windows 11 새 설치 기본)에서는 우회 버튼 없이 **막힙니다.** 이 경우 실행할 수 없습니다.
- 브라우저 다운로드에도 "일반적으로 다운로드되지 않음" 경고가 붙을 수 있습니다.
